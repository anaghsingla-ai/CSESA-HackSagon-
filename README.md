# 🎮 QuestBoard  
## Gamified Kanban RPG Productivity System

QuestBoard is a full-stack web application that combines a Kanban task manager with RPG-style gamification to make productivity engaging and motivating.

---

## 🚀 Features

- 🗂 Kanban Board (To-Do, In Progress, Completed)
- 📅 Task scheduling (deadlines, daily/weekly tasks)
- 🎮 XP & Leveling system
- 🪙 Coins & reward system
- 🏆 Achievement badges
- 🧙 Avatar / character system
- ❤️ Optional health system (missed tasks reduce health)
